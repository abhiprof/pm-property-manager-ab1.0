# Property Manager

## Overview
Property Manager is a web application that allows users to manage their properties efficiently. Users can add, delete, view, and modify property details through an intuitive interface.

## Tech Stack

### Frontend
- React

### Backend
- Express.js
- SQL Database

## Features
- Add new properties
- View all properties
- Modify existing property details
- Delete properties

## Getting Started

### Prerequisites
- Node.js
- npm or yarn
- SQL Database

### Installation
1. Clone the repository
2. Install frontend dependencies: `npm install` (in frontend directory)
3. Install backend dependencies: `npm install` (in backend directory)
4. Configure database connection
5. Start the development server
